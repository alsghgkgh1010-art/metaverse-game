# 교실용 메타버스 교육 게임

초등학교 5~6학년이 수업 시간에 직접 플레이하는 교육용 게임 모음입니다.
**인터넷 없이, 파일 하나로, 더블클릭만으로** 실행됩니다.

## 산출물

| 파일 | 내용 | 교과 | 상태 |
|---|---|---|---|
| `조선시대-퀴즈맵.html` | 2D 탑다운 방탈출 퀴즈 (젭퀴즈 방식) | 사회 5-2 (한국사) | 제작 중 |
| `우주탐사-RPG.html` | 3D 3인칭 탐험 (천체별 중력 체험) | 과학 5-1 (태양계와 별) | 예정 |
| `교사용-수업안내.md` | 차시 계획 · 발문 · 인쇄용 활동지 | — | 예정 |

## 여는 방법

파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치도, 로그인도, 인터넷도 필요 없습니다.

### 학생 기기에 배포하기

| 기기 | 방법 |
|---|---|
| 교실 PC · 학생 노트북 | USB나 공유폴더로 복사 → 더블클릭 |
| 크롬북 | 다운로드 후 파일 앱에서 열기 |
| **태블릿(아이패드 등)** | 로컬 파일 실행이 막히므로 **웹에 올려 링크로** 배포 |

> ⚠️ **구글 드라이브 링크는 작동하지 않습니다.** 드라이브는 HTML을 실행하지 않고 다운로드만 시킵니다.
> 태블릿을 쓴다면 구글 사이트 도구나 GitHub Pages에 파일을 올려 주소로 접속하게 하세요.

## 문항 바꿔서 다른 수업에 쓰기

`조선시대-퀴즈맵.html`을 메모장이나 VS Code로 열면 파일 맨 위에 `문제은행` 목록이 있습니다.
**이 부분만 고치면** 과학·영어·국어 등 어느 과목으로든 바꿀 수 있습니다. 나머지는 건드릴 필요 없습니다.

## 이어서 할 일 (2026-09-08 중단 지점)

### ✅ 완료 — 2D 퀴즈맵 비주얼 전면 개선 (2026-09-09)
타일 48px, 2.5D 벽, 등롱 조명, 소품 8종, 이름표, 족자, 비네트, 입자까지 모두 반영.
`스크린샷/퀴즈맵-*.png` 참고.

### ✅ 해결 — 화면 전환 버그
`#start{display:grid}` (아이디, 1-0-0) 가 `.screen{display:none}` (클래스, 0-1-0) 을 이겨서
**시작 화면이 절대 숨겨지지 않았다.** 게임은 그 아래에 깔려 있었다.
`display` 규칙을 `.on` 상태로 옮기고 `!important` 를 붙여 해결.

### 3D (우주탐사-RPG) 남은 단계
- 페이즈 4: 미션 6종 + 태양계 지도(실제 비율 토글)
- 페이즈 5: 배포용 단일 HTML 빌드 (three.js 인라인), 교사용 수업안내, 활동지
- 페이즈 6: 공모전 제출용 소개자료·시연 시나리오

### 개발 메모
- 3D는 개발 중 `vendor/` 를 참조한다. 배포 시 `<script src>` 를 라이브러리 소스로 통째로 바꿔 단일 파일로 만든다.
- 두 게임 모두 주소 끝에 `?start=1` 을 붙이면 시작 화면을 건너뛴다. (3D는 `&body=moon` 등도 가능)
- 자세한 규칙은 `CLAUDE.md`, 설계 근거는 `계획서.md` 와 `PRD.md` 참고.
