# 교실용 메타버스 교육 게임

초등학교 5~6학년이 수업 시간에 직접 플레이하는 교육용 게임 모음입니다.
**인터넷 없이, 파일 하나로, 더블클릭만으로** 실행됩니다.

## 산출물

| 파일 | 내용 | 교과 | 상태 |
|---|---|---|---|
| `조선시대-퀴즈맵.html` | 2D 탑다운 탐험 퀴즈 — 아바타 꾸미기 · 엽전 · 숨은 유물 · NPC | 사회 5-2 (한국사) | 플레이 가능 |
| `우주탐사-RPG.html` | 3D 3인칭 탐험 — 임무 12단계 · 암석 표본 · 사진첩 · 탐사 보고서 | 과학 5~6학년 (지구의 운동) | 플레이 가능 |
| `교사용-수업안내.md` | 차시 계획 · 발문 · 인쇄용 활동지 | — | 예정 |

## 여는 방법

파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치도, 로그인도, 인터넷도 필요 없습니다.

### 학생 기기에 배포하기

| 기기 | 방법 |
|---|---|
| 교실 PC · 학생 노트북 | USB나 공유폴더로 복사 → 더블클릭 |
| 크롬북 | 다운로드 후 파일 앱에서 열기 |
| **태블릿(아이패드 등)** | 로컬 파일 실행이 막히므로 **웹에 올려 링크로** 배포 |

> ⚠️ **구글 드라이브 링크는 작동하지 않습니다.** 드라이브는 HTML을 실행하지 않고 다운로드만 시킵니다.
> 태블릿을 쓴다면 구글 사이트 도구나 GitHub Pages에 파일을 올려 주소로 접속하게 하세요.

## 문항 바꿔서 다른 수업에 쓰기

`조선시대-퀴즈맵.html`을 메모장이나 VS Code로 열면 파일 맨 위에 `문제은행` 목록이 있습니다.
**이 부분만 고치면** 과학·영어·국어 등 어느 과목으로든 바꿀 수 있습니다. 나머지는 건드릴 필요 없습니다.

## 원칙

- 외부 네트워크 요청 0건 — 학교 방화벽·오프라인에서도 그대로 동작
- 학생 개인정보를 수집하거나 전송하지 않음 (닉네임만, 기기 내 저장)
- 로그인·서버·설치 없음
- 본문 18px 이상, 터치 타겟 44px 이상 — 프로젝터와 태블릿 모두 대응

## 이어서 할 일 (2026-09-09 현재)

### 확인이 필요한 것 (가장 먼저)
- **실제 브라우저에서 두 게임을 끝까지 한 번씩 플레이해 볼 것.** 헤드리스 검증만 마친 상태다.
  - 3D: 화성 '가장 높은 곳'이 걸어서 오를 만한 경사인지, 표본이 지형에 파묻히지 않는지
  - 2D: 엽전을 주우러 다니는 동선이 실제로 재미있는지, 맵이 지루하지 않은지
- 3D 사진 촬영은 `preserveDrawingBuffer` 없이 렌더 직후 캡처한다.
  오래된 GPU 드라이버에서 빈 이미지가 나올 여지가 있다(보고서에는 캡션이 남는다).

### 남은 단계
- 배포용 단일 HTML 빌드 — 3D의 `<script src="vendor/...">` 를 라이브러리 소스로 인라인
- `교사용-수업안내.md` — 차시 계획·발문·인쇄용 활동지
- 공모전 제출용 소개자료·시연 시나리오

### 개발 메모
- 3D는 개발 중 `vendor/` 를 참조한다. 배포 시 인라인한다.
- 두 게임 모두 주소 끝에 `?start=1` 을 붙이면 시작 화면을 건너뛴다. (3D는 `&body=moon` 등도 가능)
- 자세한 규칙은 `CLAUDE.md`, 설계 근거는 `계획서.md` 와 `PRD.md` 참고.
