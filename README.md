# 교실용 메타버스 교육 게임

초등학교 5~6학년이 수업 시간에 직접 플레이하는 교육용 게임 모음입니다.
**인터넷 없이, 파일 하나로, 더블클릭만으로** 실행됩니다.

## 산출물

| 파일 | 내용 | 교과 | 상태 |
|---|---|---|---|
| `조선시대-퀴즈맵.html` | 2D 탑다운 방탈출 퀴즈 (젭퀴즈 방식) | 사회 5-2 (한국사) | 제작 중 |
| `우주탐사-RPG.html` | 3D 3인칭 탐험 (천체별 중력 체험) | 과학 5-1 (태양계와 별) | 예정 |
| `교사용-수업안내.md` | 차시 계획 · 발문 · 인쇄용 활동지 | — | 예정 |

## 여는 방법

파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치도, 로그인도, 인터넷도 필요 없습니다.

### 학생 기기에 배포하기

| 기기 | 방법 |
|---|---|
| 교실 PC · 학생 노트북 | USB나 공유폴더로 복사 → 더블클릭 |
| 크롬북 | 다운로드 후 파일 앱에서 열기 |
| **태블릿(아이패드 등)** | 로컬 파일 실행이 막히므로 **웹에 올려 링크로** 배포 |

> ⚠️ **구글 드라이브 링크는 작동하지 않습니다.** 드라이브는 HTML을 실행하지 않고 다운로드만 시킵니다.
> 태블릿을 쓴다면 구글 사이트 도구나 GitHub Pages에 파일을 올려 주소로 접속하게 하세요.

## 문항 바꿔서 다른 수업에 쓰기

`조선시대-퀴즈맵.html`을 메모장이나 VS Code로 열면 파일 맨 위에 `문제은행` 목록이 있습니다.
**이 부분만 고치면** 과학·영어·국어 등 어느 과목으로든 바꿀 수 있습니다. 나머지는 건드릴 필요 없습니다.

## 원칙

- 외부 네트워크 요청 0건 — 학교 방화벽·오프라인에서도 그대로 동작
- 학생 개인정보를 수집하거나 전송하지 않음 (닉네임만, 기기 내 저장)
- 로그인·서버·설치 없음
- 본문 18px 이상, 터치 타겟 44px 이상 — 프로젝터와 태블릿 모두 대응
